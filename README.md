## 先分清三种“家宽 IP”，否则比价没有意义

平台风控看的不是你宣传页上写了什么，而是三个可以查的东西：ASN 归属、IP 类型标记、欺诈评分。机房 IP 的 ASN 挂在云厂商或 IDC 名下，类型是 `datacenter` 或 `hosting`；真家宽 IP 的 ASN 挂在运营商名下，类型是 `residential` 或 `isp`，地理位置落到具体居民区。这两类在 TikTok、Amazon、Netflix 眼里不是同一个物种。

市场上的产品大致分三档：

**第一档，纯机房 IP。** 便宜、带宽大、随开随用，但它就是明牌告诉平台“我是服务器”。拿它养号，等于开局自我介绍。

**第二档，机房托管 + 住宅属性 IP。** 机器还在数据中心，分到的是被标记为住宅或 ISP 类型的地址。IP 查询结果好看，但机房 IP 段被大量循环使用，同一批地址可能已经进过别人的黑名单。这类产品价格通常在几十元一个月，适合对成本敏感、只做轻量操作的场景。

**第三档，真民宅托管。** 服务器物理上放在美国居民住宅里，光纤是向 Atlas Networks、Astound Broadband、T-Mobile、Frontier 这类当地运营商申请的，IP 就是那户人家的宽带地址。丽萨主机的家宽 VDS 属于这一档，官方页面写得很直白：“所有硬件均托管在真实的美国家庭住宅房屋中，向当地宽带运营商申请安装的光纤宽带。”

第三档有个绕不开的副作用：**供货受限**。一根光纤能分出来的地址是固定的，扩容意味着重新找房、报装宽带、等运营商上门，周期以周甚至月计。所以真家宽产品经常断货或预售，这不是商家饥饿营销，是物理限制。

“双 ISP”是另一个容易混淆的概念。它指同一个 IP 同时挂靠两个互联网服务提供商，平台在做归属识别时会觉得更像真实住宅用户，被标记的概率低于单 ISP。丽萨主机在两条产品线上都用了这个思路：民宅托管的 VDS 走当地运营商线路，另有一条 9929 精品网的机房托管双 ISP 住宅 IP 产品线，入门档 68 元/月。后者的机器在洛杉矶机房，不是民宅，价格和定位都不同，具体以官网为准。

丽萨主机本身是一家香港公司，在这个品类里做了六七年，产品线覆盖美国、香港、日本、韩国、新加坡、英国、越南等地。这篇只谈美国家宽，其他地区不在讨论范围。

## 常见问题

**家宽 IP 就一定干净吗？**
不一定，而且没有任何商家能保证长期纯净。同一批 IP 会在用户之间循环销售，部分地址段可能已经被平台标记过。能确定的是：独享静态比共享 NAT 抗污染，真民宅托管比机房挂住宅属性更难被识别。别把“IP 纯净”当成永久承诺。

**静态独享和共享 NAT 怎么选？**
要长期维护账号身份、绑定支付方式、跑店铺后台，选静态独享——IP 是你一个人的，别人污染不到。只是临时解锁流媒体、做短期测试，共享 NAT 更便宜，但同 IP 上别人的行为会影响你。

**双 ISP 有什么用？**
让同一个 IP 同时挂靠两个运营商，风控识别时更接近真实住宅用户的网络特征，被标记概率低于单 ISP。预算允许优先双 ISP，但它不是万能护身符。

**国内访问慢怎么办？**
这是家宽产品的普遍特征，不是某一家的问题。解决办法是搭配一条优化线路做中转，官方也这么建议。别指望家宽 VDS 直连能跑出机房优化线路的延迟。

**能装 Windows 吗？**
可以，官方明确支持安装 Windows。对不习惯命令行的用户，直接远程桌面操作就行。

**西雅图和洛杉矶怎么选？**
运营商不同（Atlas Networks vs Astound Broadband），进阶、豪华、不限流量几档两地同价同配置。西雅图多送 5 个 IPv6，且独有 169 元入门档；洛杉矶没有 169 元档。业务没有特定地区要求，优先看西雅图。
